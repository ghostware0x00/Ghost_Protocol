
### WHY CMAKE ANYWAY

#### Exact Process Breakdown
1. CMake reads your CMakeLists.txt file.This file serves as your high-level blueprint.
2. CMake evaluates this blueprint against your specific operating system. It then generates the low-level build system files (like Makefile or build.ninja)
3. The generated build system acts as the coordinator. It reads the instructions generated by CMake and calculates the exact file dependencies.
4. The build system directly invokes your C++ compiler (like g++ or clang++). It passes the exact flags and source files required to build your final executable.

```bash
┌─────────────────────────────────────────────────────────┐
│                   CMake (Meta-Build Tool)               │  <-- Processes "CMakeLists.txt"
└────────────────────────────┬────────────────────────────┘
                             │ (Generates)
                             ▼
┌─────────────────────────────────────────────────────────┐
│               Make / Makefiles (Build System)           │  <-- Tracks targets and file changes
└────────────────────────────┬────────────────────────────┘
                             │ (Invokes)
                             ▼
┌─────────────────────────────────────────────────────────┐
│             Compiler & Linker (g++, clang++, etc.)       │  <-- Compiles .cpp to .o; links binaries
└─────────────────────────────────────────────────────────┘

```
